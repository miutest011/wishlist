# 心愿单

随手记下被种草的东西：从相册选一张图或一段视频，写句备注，就成了一条记录。
首页是一面贴满拍立得的墙，两列，每张微微歪一点。

纯前端，没有用任何框架和构建工具，数据都存在你自己的设备里，不上传到任何服务器。

## ⚠️ 数据只有这一份

照片和视频是**复制**进这个 App 的，所以相册里的原件可以删掉。
但反过来说，App 里这份就是唯一的一份，下面几种情况会丢：

- 把这个 App 从主屏幕删掉
- 在设置里清除 Safari 的网站数据
- 手机存储严重不足时，系统可能回收网页存储
- 换手机（数据不会跟着走）

网页启动时会向浏览器申请「持久存储」，能大大降低被系统回收的概率，但不是保险箱。
**备份导出功能还没做，这是下一步最优先的事**，做好之前别把重要的原图删干净。

## 文件结构

```
index.html      页面骨架
style.css       样式
media.js        存储层：文件存取（IndexedDB）+ 生成缩略图
app.js          界面逻辑：宫格、写备注、看详情、删除
manifest.json   PWA 配置（应用名、图标、启动方式）
sw.js           Service Worker，负责离线缓存
icons/          应用图标
tools/          测试工具（见 tools/README.md）
```

`media.js` 和 `app.js` 分开是有意的：界面代码不直接碰 IndexedDB，
以后把这个网页装进 iOS App 时，只要换掉 `media.js`，界面代码一行都不用动。

## 样式规则

改样式只改 `style.css` 顶部那一组变量，别在具体组件里写死颜色和数值。规则是：

- **底色是干净的白**，照片是主角，界面本身尽量不出声音
- **只用黑白灰**，没有主题色 —— 一有彩色按钮就显得廉价；只有「删除」用一点红
- **相框**是白纸 + 极淡的描边 + 两层柔和的影子，白底上全靠影子把照片托起来
- **倾斜最多 2.5 度**，再多就像贴纸墙
- **悬浮控件**（＋ 按钮、顶栏、提示框）是半透明白 + 毛玻璃，下面的内容要隐约透出来
- **标题用系统自带的圆体**，不下载网络字体（几 MB，还要联网，离线就废了）

改完打开 `tools/gallery.html`（样板页），一屏就能看出哪里坏了 ——
那一页是用 App 真正的代码画的，所以不会和实际效果走偏。

## 在电脑上打开

直接双击 `index.html` 就能用。

想测试 PWA 相关功能（安装、离线）的话，必须通过服务器打开：

```bash
python3 tools/dev-server.py
```

然后访问 http://localhost:4173

> 用这个脚本而不是 `python3 -m http.server`，因为它会明确告诉浏览器**不要缓存文件**。
> 用自带的那个服务器，改完代码刷新页面看到的常常还是旧版本。

## 装到 iPhone 上

**前提：必须是 https 网址。** 手机直接访问 `http://192.168.x.x:4173` 这种局域网地址
是不行的 —— 浏览器只在 https 或 localhost 下才允许 Service Worker 运行。

### 用 GitHub Pages 发布（免费）

1. 在 [github.com/new](https://github.com/new) 建一个仓库（**Public**，免费版的 Pages 需要公开仓库）

2. 把代码推上去（把网址换成你自己的）：

```bash
git remote add origin https://github.com/你的用户名/仓库名.git
```

```bash
git push -u origin main
```

3. 仓库页面点 **Settings → Pages**，Source 选 `Deploy from a branch`，
   分支选 `main`、目录选 `/ (root)`，保存

4. 等一两分钟，网址会是 `https://你的用户名.github.io/仓库名/`

代码是公开的，但**你的照片和备注不会上传**，它们只存在你自己的手机里。

### 添加到主屏幕

在 iPhone 上**用 Safari**打开那个网址（Chrome 不行，iOS 只有 Safari 支持添加 PWA）：

分享按钮 → 添加到主屏幕 → 添加

## 怎么用

| 想做什么 | 怎么做 |
|---|---|
| 记一条种草 | 点底部的 ＋ → 选照片或视频 → 写备注（可以不写）→ 完成 |
| 看大图、看备注 | 点一下那张拍立得 |
| 改备注 | 在详情页直接改，边打字边存 |
| 删掉 | 详情页右上角「删除」，会问一句再删 |
